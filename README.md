# เช็คพาสงาน (TTScan)

แอป Android สแกน QR บนใบ TT เพื่อเช็คว่างานนั้นถ่ายรูปเก็บแล้วหรือยัง
ถ้ายังไม่ได้ถ่าย จะให้ถ่าย 2 รูป แล้วสร้างโฟลเดอร์ชื่อเดียวกับ QR พร้อมเซฟรูปให้อัตโนมัติ

## วิธีใช้งาน

1. เปิดแอปครั้งแรก เลือก **ที่เก็บงาน** จะเป็นโฟลเดอร์ในมือถือหรือ USB (ต่อสาย OTG) ก็ได้ แอปจะจำไว้ เปลี่ยนได้ด้วยปุ่ม "เลือกที่เก็บงาน"
2. เล็งกล้องไปที่ QR บนใบ TT
   - **✅ สีเขียว** = มีโฟลเดอร์และรูปครบแล้ว ไม่ต้องถ่ายซ้ำ
   - **🆕 สีส้ม** = ยังไม่ได้ถ่าย แอปเข้าโหมดถ่ายรูปให้เอง
3. กด "ถ่ายรูป" 2 ครั้ง พอครบแอปจะสร้างโฟลเดอร์และบันทึกรูปทันที แล้วกลับไปโหมดสแกนต่อ

ตัวอย่างผลลัพธ์ในที่เก็บงาน:

```
FG-3673120100-01/
    FG-3673120100-01_1.jpg
    FG-3673120100-01_2.jpg
```

ปุ่ม "รายการที่ถ่ายแล้ว" แสดงโฟลเดอร์งานทั้งหมดที่มีในที่เก็บ

## ทำเป็นไฟล์ติดตั้ง (APK)

ดูขั้นตอนละเอียดใน `BUILD_FOR_AI.md` (ให้ AI หรือโปรแกรมเมอร์ทำตามได้เลย)

สรุปสั้น ๆ: ต้องมี JDK 17 + Android SDK 34 แล้วรัน

```
./gradlew assembleDebug
```

ได้ไฟล์ `app/build/outputs/apk/debug/app-debug.apk`

หรือใช้ GitHub Actions: อัปโหลดไฟล์ทั้งหมดขึ้น GitHub แล้ว workflow "Build APK" ใน `.github/workflows/build.yml` จะ build ให้เอง

## หมายเหตุ

- ไม่ต้องใช้อินเทอร์เน็ตตอนใช้งาน โมเดลสแกน QR ฝังอยู่ในแอป (ตอน build ต้องใช้เน็ต)
- ชื่อโฟลเดอร์ใช้ข้อความใน QR ตรง ๆ ถ้ามีอักขระที่ระบบไฟล์ไม่รับ (`/ \ : * ? " < > |`) จะถูกแทนด้วย `_`
- แอปเช็คเฉพาะโฟลเดอร์ชั้นแรกในที่เก็บงานที่เลือก
- โฟลเดอร์ที่มีรูปน้อยกว่า 2 รูป ถือว่ายังไม่ครบ แอปจะให้ถ่ายใหม่และเขียนทับ
- ขั้นต่ำ Android 7.0 (API 24)
